[ ] 1. فاز صفر: تشخیص وضعیت کلی بازار (Market Health) - اولویت یک
    [ ] 1-1. نوشتن تابع `calculate_market_health()` در فایل `core/market_health.py`
    [ ] 1-2. این تابع باید ۳ شاخص اصلی را محاسبه کند:
         [ ] 1-2-1. نسبت تعداد سهام صعودی به نزولی (Advance/Decline Ratio)
         [ ] 1-2-2. نسبت پول حقیقی به حقوقی در کل بازار
         [ ] 1-2-3. مقایسه‌ی شاخص کل با میانگین متحرک ۲۰ روزه
    [ ] 1-3. خروجی تابع: یک عدد بین ۰ تا ۱۰۰
         [ ] ۰ تا ۳۵ = وضعیت قرمز (خطر ریزش، دست نگه دار)
         [ ] ۳۵ تا ۶۵ = وضعیت زرد (صبر کن، سیگنال مطمئن نیست)
         [ ] ۶۵ تا ۱۰۰ = وضعیت سبز (آزاد به خرید و نوسان‌گیری)
    [ ] 1-4. اضافه کردن هشدار در `main.py` که قبل از هر کاری، این تابع را صدا بزند

[ ] 2. فاز اول: موتور نوسان‌گیری روزانه با محوریت ریسک
    [ ] 2-1. نوشتن کلاس `SwingEngine` در `engines/swing_engine.py`
    [ ] 2-2. پیاده‌سازی قانون ذهنی «منفی ۳ بخر، مثبت ۳ بفروش»
    [ ] 2-3. اضافه کردن کارمزد ۱.۲۵٪ به عنوان «مقاومت سود» (اگر سود پیش‌بینی‌شده کمتر از ۲٪ است، پیشنهاد نده)
    [ ] 2-4. افزودن فیلتر «حجم فروش حقوقی»: اگر بیش از ۷۰٪ معاملات فروش حقوقی بود، سیگنال خرید نده (حتی اگر به منفی ۳ رسیده باشد)
    [ ] 2-5. خروجی: فقط ۳ سهم برتر برای نوسان‌گیری روزانه

[ ] 3. فاز دوم: موتور سرمایه‌گذاری بلندمدت (برای روزهایی که بازار سبز است)
    [ ] 3-1. نوشتن کلاس `LongTermEngine` در `engines/long_term_engine.py`
    [ ] 3-2. اضافه کردن معیارهای بنیادی: نسبت P/E پایین‌تر از صنعت، رشد سود ۳ ساله، نسبت بدهی مناسب
    [ ] 3-3. خروجی: ۵ سهم برای سرمایه‌گذاری با افق ۶ ماه تا ۱ سال

[ ] 4. فاز سوم: بهینه‌سازی با بک‌تست (همان مغز شطرنجی)
    [ ] 4-1. نوشتن کلاس `BacktestOptimizer` در `ai/backtest_optimizer.py`
    [ ] 4-2. تست قانون «منفی ۳ بخر، مثبت ۳ بفروش» روی داده‌های ۵ ساله
    [ ] 4-3. پیدا کردن بهترین آستانه‌ها (به جای ۳، عدد بهینه را پیدا کن)
    [ ] 4-4. شبیه‌سازی سناریوی ریزش ۱/۵ (مثل سال قبل) و بررسی عملکرد سیستم

[ ] 5. فاز چهارم: اتوماسیون و گزارش‌گیری روزانه (سبک و سریع)
    [ ] 5-1. نوشتن `daily_runner.py` که هر روز صبح ساعت ۸ اجرا شود
    [ ] 5-2. ذخیره‌سازی خودکار داده‌های روزانه در `data/history/`
    [ ] 5-3. تولید خروجی نهایی: فقط ۵ خط (وضعیت بازار + ۳ نوسان‌گیر برتر + ۲ بلندمدت برتر)
    [ ] 5-4. ارسال خروجی به یک فایل `reports/daily_signal.txt` (تا بتوانی در فروشگاه یا مدرسه بخوانی)
